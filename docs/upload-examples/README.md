# Примеры файлов загрузки заявлений

## Общие правила

- **Строка 1** — тип заявления на русском (`Банковский продукт`, `Банковская услуга`, …).
- **Строки 2+** — данные без заголовков колонок, строгий порядок полей.
- **txt** — разделитель табуляция (`\t`), пропуск поля = две табуляции подряд.
- **xlsx** — строка 1 колонка A = тип; данные с строки 2, колонки A…
- **Даты** — `dd.MM.yyyy`
- **Enum** — русские значения (см. contracts enum `fileLabel`)
- **Канал** — не указывается, при загрузке всегда `FILE`

## Файлы

| Файл | Назначение |
|------|------------|
| `product-valid.txt` | Валидный продуктовый файл (2 заявления) |
| `product-valid.xlsx` | То же в xlsx |
| `product-invalid-enum-row3.txt` | Ошибка enum в строке 3 |
| `service-valid.txt` | Валидный файл услуг |
